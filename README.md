# MCP Prompt Injection & Tool Security Lab

## Overview
This project explores how LLMs use tools via MCP and analyzes security risks such as prompt injection and tool poisoning.

## Objectives
- Understand MCP tool usage
- Simulate tool interactions
- Analyze attack patterns
- Propose defenses

## Folder Structure
- reports/ → summaries & final analysis
- examples/ → tool interaction demos
- dataset/ → attack dataset
